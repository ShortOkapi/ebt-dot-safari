# EBT Dot Safari → EBT DotPick

EBT Dot Safari is now **[EBT DotPick](https://shortokapi.github.io/ebt-dotpick/)**.

- [Current repository, history and Releases](https://github.com/ShortOkapi/ebt-dotpick)
- [User guide](https://github.com/ShortOkapi/ebt-dotpick#how-to-use)
- [Historical v2.2.1 release](https://github.com/ShortOkapi/ebt-dotpick/releases/tag/v2.2.1)

This small compatibility site keeps the former web address useful. Its service worker replaces the old app shell with the forwarding page while retaining public dataset caches and personal browser storage. An existing installation may need a second online launch/reload before it reaches this page. Installed-app update behaviour must be checked on Android and iPhone; keep an old installation until the new app and its conquered dots have been checked.

The active application is maintained only in **ebt-dotpick**. This forwarding repository contains no app data lists or preparation scripts. Source history and existing release tags remain in the renamed original repository.
