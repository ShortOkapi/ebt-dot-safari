# EBT Dot Safari 🌍🧭

A live GPS tracking tool and heatmap for EuroBillTracker map dot hunters.

## Features
* **Live Target Compass**: Uses your phone's GPS to calculate the exact distance and bearing to the nearest unconquered dot.
* **Offline Ready**: Works completely offline as a Progressive Web App (PWA). Just load it once and add it to your home screen.
* **Privacy First**: All CSV parsing happens locally in your browser. No data is ever uploaded to a server.

## How to Use
1. Export your notes CSV from EuroBillTracker.
2. Open EBT Dot Safari on your phone.
3. Tap **Load EBT Notes File** and select your CSV.
4. Allow location access, and start hunting!
